# Site local — Firawynix Dock

Abra `index.html` no navegador. O site é estático e não precisa de servidor ou instalação. A demonstração permite filtrar cartões e ajustar a transparência do painel ilustrativo.

O site também está publicado no lab, com acesso público: https://lab.firawynix.com.br/dock/ .

A captura em `assets/dock-preview.png` foi gerada pelo próprio aplicativo com `FirawynixDock.exe --preview`. Os ícones de exemplo vieram do cache local do Dock. O site mostra que o envio está em certificação; depois da aprovação, substitua os avisos de certificação pelos links do produto `9MT74R15N5JQ` na Microsoft Store.
